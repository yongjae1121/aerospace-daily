# Aerospace Daily — 매일 한 걸음, 항공우주공학

기초 물리부터 로켓·공기역학·궤도역학·엔진·구조·우주선 시스템까지, **160일 동안 하루 한 강좌씩** 배우는 개인 학습 사이트입니다. 강좌마다 핵심 영단어와 영어 지문이 있어 전공 영어도 함께 익힐 수 있습니다.

## 매일 이렇게 써요

1. 사이트에 들어가면 **오늘의 강좌**가 열려 있어요.
2. 본문 → 📘 핵심 영단어(🔊로 발음 듣기) → 📖 English Reading(소리 내어 따라 읽기, 밑줄 단어를 누르면 뜻) → ✏️ 확인 문제 → **오늘 학습 완료** 버튼.
3. **단어장 → 플래시카드 복습**: 외운 단어는 잊어버릴 때쯤(1·3·7·16·35일 뒤) 다시 나와요.
4. **테스트**: 7일마다 주간 테스트, 단원이 끝나면 단원 평가가 열려요. 언제든 랜덤 연습과 영단어 테스트도 볼 수 있어요.

## 자동 업데이트는 이렇게 돌아가요

```
매일 새벽 (한국 시간)
  Claude 예약 루틴이 GitHub 저장소를 열어
  → 다음 강좌(본문·단어·지문·문제)를 작성
  → 자동 검사(형식·수식 오류) 통과 시 저장소에 올림
  → GitHub가 사이트를 다시 만들어 배포
아침에 사이트를 열면 새 강좌가 와 있음
```

강좌는 이틀 정도 미리 작성되어 있어서, 하루쯤 루틴이 실패해도 다음 날 밀린 강좌를 따라잡아요.

## 학습 기록

진도·점수·단어 암기 기록은 **지금 쓰는 기기의 브라우저**에 저장돼요. 휴대폰과 컴퓨터를 오가거나 브라우저 기록을 지우기 전에는 **설정(⚙️) → 백업 파일 저장**을 눌러 두고, 다른 기기에서 **백업 불러오기**를 하세요.

## 바꾸고 싶은 게 있으면

코드를 직접 만질 필요 없어요. Claude Code에서 이 폴더를 열고 말로 부탁하면 돼요. 예를 들어:

- "강좌를 조금 더 짧게 써 줘" / "영어 지문을 더 어렵게 해 줘"
- "궤도역학 단원을 더 앞으로 옮겨 줘"
- "주간 테스트 문제 수를 30개로 늘려 줘"
- "홈 화면에 D-day 카운터를 추가해 줘"

기술적인 작업 규칙은 [CLAUDE.md](CLAUDE.md)에 정리되어 있어요.
